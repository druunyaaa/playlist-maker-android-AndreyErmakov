# Playlist Maker 🎵

Мобильное приложение для поиска музыки и управления медиатекой. Проект реализован на современном стеке разработки под Android с использованием декларативного UI и принципов чистой архитектуры.

---

## 🚀 Основные возможности

* **Поиск музыки**: Быстрый поиск треков через iTunes API с отображением результатов в реальном времени.
* **История поиска**: Сохранение последних запросов для быстрого доступа.
* **Управление плейлистами**: Создание собственных плейлистов, добавление описаний и выбор обложек из галереи устройства.
* **Избранное**: Возможность отмечать треки и хранить их в отдельном списке (локальная БД).
* **Полнофункциональный плеер**: Прослушивание превью, просмотр информации о треке и добавление в плейлисты прямо с экрана проигрывателя.
* **Обмен данными**: Возможность делиться списком треков из плейлиста через сторонние приложения.

## ⚙️ Сборка и запуск

1.  **Клонирование репозитория**
    ```bash
    git clone https://github.com/druunyaaa/playlist-maker-android-AndreyErmakov.git
    ```

2.  **Открытие проекта**
    * Запустите Android Studio.
    * Выберите **Open** и укажите путь к папке `playlist-maker-android`.

3.  **Синхронизация Gradle**
    * Дождитесь завершения загрузки всех зависимостей. Приложение использует Room и Retrofit, поэтому потребуется стабильное интернет-соединение.

4.  **Запуск приложения**
    * Подключите физическое устройство (Android 10+) или запустите эмулятор.
    * Нажмите **Run 'app'** (Shift + F10).

---

## 📂 Структура проекта

* `data/`: Реализация сетевых запросов (Retrofit), базы данных (Room) и репозиториев.
* `domain/`: Модели данных и интерфейсы бизнес-логики.
* `ui/`: Пользовательский интерфейс на Jetpack Compose, ViewModels и навигация.
